# motiontext

[English](README.md) | **日本語**

歌詞の字幕ファイルを読み込むだけで、リリックビデオ風の文字アニメーションを自動で作る Web アプリです。
作った映像は、手持ちの MV（ミュージックビデオ）に重ねて使えます。

**▶ アプリを開く： [https://louddrive.github.io/motiontext/](https://louddrive.github.io/motiontext/)**

- **インストール不要・無料**：ブラウザで開くだけで使えます。
- **字幕を入れるだけで自動生成**：文字の動き・配置・色・縦書きなどを自動で決めます。気に入らなければボタン1つで作り直せます。
- **データはどこにも送信されません**：字幕や MV は、あなたのパソコンのブラウザの中だけで処理されます。
- **5言語に対応**：画面の表示を英語・日本語・简体中文・繁體中文・한국어 から選べます（左上の言語メニュー）。

## 必要なもの

### 1. パソコンと、Chrome または Edge

- **Google Chrome** または **Microsoft Edge** の最新版を使ってください。
- Safari・Firefox・スマートフォンでは、書き出しの一部（または全部）が使えません。

### 2. 歌詞の字幕ファイル（SRT または SBV）

字幕ファイルは、「どの時間に、どの歌詞を表示するか」を書いたテキストファイルです。拡張子は `.srt` か `.sbv` です。

SRT 形式の例：

```text
1
00:00:12,500 --> 00:00:15,000
夜明けの街を歩いていく

2
00:00:15,200 --> 00:00:18,000
君の笑顔を忘れないように
```

- 番号、表示する時間（開始 --> 終了）、歌詞の順に並べ、字幕ごとに空行で区切ります。
- YouTube Studio の字幕の編集画面から、`.srt` や `.sbv` 形式でダウンロードできます。字幕作成ソフトで作ったものも使えます。
- 文字コードは UTF-8 と Shift_JIS に対応しています（どちらか分からなくても、自動で判別します）。
- サンプルの字幕として [tests/fixtures/sample.srt](tests/fixtures/sample.srt) があります。まず試したいときに使ってください。

### 3.（任意）重ねたい MV や曲のファイル

- 仕上がりを確認するとき、または「MV／曲と合成」で書き出すときに使います。
- MV は **H.264 形式の MP4** がおすすめです。

## はじめての使い方（5ステップ）

画面の左側に設定と操作、右側にプレビューが並びます。左側は「1. 字幕・音源」〜「5. 書き出し」に分かれていて、上から順に進めれば完成します。各欄の見出しをクリックすると、その欄を閉じたり開いたりできます。

> 画面の言語は、ブラウザの言語設定に合わせて自動で選ばれます（日本語・中国語・韓国語以外は英語）。左上の言語メニューで切り替えられます。
> 選んだ言語は URL（`?lang=ja` など）に反映されるので、ブックマークしておけば次回も同じ言語で開きます（ブラウザには保存しません）。

### ステップ 1：字幕ファイルを読み込む（「1. 字幕・音源」）

1. 「**SRT / SBV ファイルをドロップ**」と書かれた枠に、字幕ファイルをドラッグ＆ドロップします。枠をクリックしてファイルを選んでもかまいません。
2. 読み込めると、ファイル名と字幕の件数が表示され、右側にプレビュー、左側に「3.」以降の欄が現れます。

- 「**MV / 音声を読み込む（任意・確認用）**」で MV や曲を読み込むと、実際に重ねたときの見え方を確認できます。
  - プレビューの下の「MVに重ねて表示」のチェックで、重ねる・重ねないを切り替えられます。
  - 読み込んだ MV／曲の長さは、書き出しの長さにも反映されます。
  - 読み込むと、曲の拍（テンポ）を自動で解析し、「曲の拍を検出しました（約 120 BPM）」のように表示します。解析はこのパソコンの中だけで行います。
    - 演出レベルが「標準」「エモい」「超エモ」のときは、**サビの歌詞の演出が自動で曲の拍に合います**（操作は要りません）。
      - サビの字幕の出る・消える時刻を、近くの拍（8分音符）に最大 0.1 秒だけ寄せます。
      - サビの文字の登場が拍の瞬間に完了し、文字が出る間隔も拍を分割した長さにそろいます。
      - サビの歌詞が拍に合わせて弾みます（拡大率は「標準」2%・「エモい」4%・「超エモ」6%。小節の頭はその 1.5 倍）。「標準」「エモい」は2拍に1回（小節の1・3拍目）、「超エモ」は毎拍弾みます。
      - サビは曲の大きい所ほど動きが強くなり、サビの頭のカメラの揺れは小節の頭で起きます。
      - サビかどうかは、歌詞の繰り返しに加えて曲の音量でも判断します。
      - 「エモい」「超エモ」では、間奏の進み具合の表示に、曲の音量に合わせて動く波形が加わります（円形では外側に放射状の棒、横型では画面中央を横切るスペアナ風の線）。
    - サビ以外の歌詞と、「演出なし」「控えめ」のときは、曲を読み込まないときと同じ演出です。
    - 拍がはっきりしない曲では、演出は曲に合わせません（その旨を表示します）。
    - 字幕全体のずれは自動では直しません。ずれている場合は、次の「字幕のタイミング」で合わせてください（拍は等間隔に並ぶので、何拍ずれているかは拍だけでは決められないため）。
    - ゆっくりした曲では、倍のテンポ（例：75 BPM の曲を約 150 BPM）と表示することがあります。
- 字幕と MV のタイミングがずれているときは、「**字幕のタイミング**」で字幕全体をずらせます。
  - 「▶」を押すと 0.1 秒ずつ遅く、「◀」を押すと 0.1 秒ずつ早く表示されます。秒数を直接入力することもできます（±30秒まで）。
  - 「↺」で 0 に戻ります。字幕ファイル自体は書き換わりません。

> 時刻の打ち間違いが疑われる字幕があると、「注意:」として表示されます。内容を確認してください。

### ステップ 2：フォントを選ぶ（「2. フォント」）

- 「**通常の行**」の書体を選びます（必須）。
- 「**強調の行（サビなど・任意）**」は、サビなどを別の書体で目立たせたいときだけ選びます。
  - 最初は「**指定しない**」になっていて、強調の行も通常の行と同じ書体・太さで表示されます（動きの演出は変わりません）。
  - 通常の行と同じ書体を選ぶと、太さの差で強弱を付けます。
- 欄をクリックすると書体の一覧が開き、読み込んだ歌詞がそれぞれの書体で表示されます。キーボードの ↑ ↓ で選び、Enter で決めることもできます。
- 一覧のバッジ（「通常行向け」「強調向け」）は、おすすめの使い方です。どちらの欄でも、すべての書体を選べます。
- 迷ったら、最初の設定（通常の行「Noto Sans JP」、強調の行「指定しない」）のままで大丈夫です。

> 日本語・韓国語・中国語（簡体字・繁体字）の書体を同梱しています（英語も表示できます）。書体に無い文字は、同梱の別の言語の書体で表示します。
> 字幕を読み込むと歌詞の言語を推定し、書体をまだ選んでいなければ、その言語の書体（例：韓国語なら Noto Sans KR）に自動で切り替えます。推定が違っていたときは、書体を選び直してください。

### ステップ 3：スタイルを選ぶ（「3. スタイル」）

- 画面の向き・演出の強さ・文字の大きさなどを選びます。
- どの項目も、選ぶとすぐ右側のプレビューに反映されます。
- 使う頻度の低い項目は、「**詳細設定**」を開くと表示されます。
- 項目の意味は [設定の説明](#設定の説明) を見てください。**最初はそのままでも大丈夫です。**
- 「**演出を再生成**」を押すと、同じ字幕で別の演出パターンを作り直します。気に入るまで何度でも押せます。
  - 「**1つ前に戻す**」で、直前のパターンに戻れます（最大100回分さかのぼれます）。
  - 「**パターン番号**」は、今のパターンの番号です。番号を控えておき、あとで入力欄に入力して Enter を押すと、同じパターンを再現できます（同じ字幕・同じ設定の場合）。

### ステップ 4：プレビューで確認する（右側）

- 「**再生**」ボタンで動きを確認できます。下のバーを動かすと、好きな時間に移動できます。
- キーボードでも操作できます（文字の入力欄や一覧を選んでいないとき）。
  - スペース：再生／停止
  - ← →：1秒戻る／進む
  - Shift ＋ ← →：0.1秒戻る／進む
- 左側の「**4. 字幕の一覧**」を開くと、字幕が時間順に並びます。行をクリックすると、その字幕の時刻に移動します。再生中の字幕は色が変わります。

### ステップ 5：書き出す（「5. 書き出し」）

1. 書き出し形式（「3. スタイル」の「出力形式」で選んだもの）に合わせたボタンを押します。
   - MP4 の場合：「**MP4 を書き出す**」。いつものダウンロードと同じように、パソコンに保存されます。
   - PNG 連番の場合：「**保存先を選んで PNG連番を書き出す**」。保存先のフォルダを選ぶ画面が開きます。
   - 合成の場合：「**保存先を選んで合成 MP4 を書き出す**」。保存するファイルの名前と場所を選ぶ画面が開きます。
2. 進み具合と残り時間の目安が表示されます。終わるまで、そのページを閉じずに待ってください。途中でやめたいときは「キャンセル」を押します。
3. 書き出したファイルを、動画編集ソフトで MV に重ねます（手順は [書き出し形式の選び方](#書き出し形式の選び方) を参照）。

> 書き出しが終わっても、画面はそのまま残ります。続けて別の形式（例：MP4 と PNG 連番の両方）でも書き出せます。
> 作業が終わったら、左側のいちばん下の「**データを破棄**」を押すか、ページを閉じてください。
> 書き出しと同時に消したい場合は、書き出す前に「書き出し後にアプリ内のデータ（字幕・MV・生成結果）を自動で破棄する」にチェックを入れてください。

## 設定の説明

「3. スタイル」の各項目の意味です。迷ったら「おすすめ」を選んでください。

| 項目 | 選べるもの | どう変わるか | おすすめ |
|---|---|---|---|
| 画面比率 | 16:9（横） / 9:16（縦・Shorts / Reels / TikTok） | 横長の動画か、スマホ向けの縦長の動画か | 通常の MV なら 16:9 |
| 演出レベル | 演出なし（可読性重視） / 控えめ / 標準 / エモい / 超エモ | 文字の動きの激しさ。上げるほど、奥行きのあるカメラの動き・縦書き・装飾・モーションブラーが増える | 日本向けは「標準」〜「エモい」、英語圏向けや読みやすさ重視なら「演出なし」 |
| 出力形式 | MP4（CapCut など） / PNG連番・背景透過（DaVinci Resolve など） / MV／曲と合成（MP4・音声付き） | 書き出すファイルの種類 | [書き出し形式の選び方](#書き出し形式の選び方) を参照 |
| 背景 | 黒 / グリーン | MP4 の背景の色。PNG 連番と合成では自動で決まる | 黒 |
| 文字サイズ | XS / S / M / L / XL（画面いっぱい） | 歌詞の大きさ。M が標準で、L は約1.5倍。「XL」は歌詞が画面いっぱいに広がる | M |
| 漢字とかなのサイズ差 | なし / 控えめ / 標準 / 強め | 漢字を大きく、ひらがなを小さくして、メリハリを付ける | 標準 |
| 画数の多い漢字を強調 | オン / オフ | 各行で、いちばん画数の多い漢字の言葉を少し大きくする | オン |
| 縦書き | 自動 / なし / 常に（日本語の行） | 日本語の歌詞を縦書きにする。「自動」では横書きと混ざる | 自動 |
| 文字色 | 自動（テーマ配色） / 単色指定 | 文字の色。単色指定では色を1つ選べる | 自動 |
| 文字の縁取り | オン / オフ | 文字のふちに細い線を付ける。色は文字色に合わせて白か黒を自動で選ぶ | 明るい MV に重ねるならオン |
| 文字の影 | オン / オフ | 文字の右下に、やわらかい影を付ける | 明るい MV に重ねるならオン |
| 背景の色レイヤー | 色（カラーピッカー）・濃さ 0〜80%・常に／歌詞の表示中だけ | MV の上（歌詞の下）に半透明の色を重ねる。明るい MV で歌詞が読みにくいときに使う。「MV／曲と合成」と「PNG連番」でだけ使える | 黒・30〜50%・歌詞の表示中だけ |

補足：

- **縦書き**になるのは、日本語だけの行です。英字や数字を含む行は、横書きのままになります。
  - 空白を含む1行の歌詞（例：「規格に合わせて　比較を消し去り」）が縦書きに選ばれると、最初の空白の前後で縦書きと横書きに分けて組みます（縦横混在）。どちらを縦にするか、L字型か逆L字型かはランダムです。文字サイズ XL では使いません。
- **「演出なし」**では、文字が動かず、ふわっと表示されて消えるだけになります。読みやすさを最優先したいときに使います。
- **演出レベル**を上げるほど、次のエフェクトが段階的に加わります。
  - モーションブラー：動いている文字がなめらかにブレます。「控えめ」から加わり、レベルが上がるほど強くなります。
  - シャイン：サビの歌詞を、光の帯が1回横切ります。「控えめ」から加わります。
  - カメラシェイク・光の粒：サビの始まりで画面が小さく揺れ、サビの歌詞の周りに光の粒が舞い上がります。「標準」から加わります。
  - グリッチ：赤と青緑の色ずれを伴って歌詞が登場します。「エモい」と「超エモ」だけで使われます。
  - 帯ワイプ・スロット・スプリット：字幕の色の帯が走った跡に文字が現れる／文字が回転ドラムのように流れて止まる／字の上下（縦書きは左右）が逆方向から来て合体する、の3つの登場の演出です。「標準」から加わります。
  - アウトラインの反復：縁取りだけの文字が何重にもずれて重なり、本体に収束します。「エモい」と「超エモ」だけで使われます。
  - 線：歌詞の登場に合わせて、横書きは行の下、縦書きは列の右側に線が伸びながら引かれます。サビに限らず字幕ごとの抽選で、確率は「控えめ」15%・「標準」25%・「エモい」35%・「超エモ」45%です。
  - 間奏の進み具合：歌詞の間が5秒以上ある間奏で、横線または円と、カウントアップするパーセンテージを表示します。最初はゆっくり進み、最後の約1秒で一気に100%に達して、その直後に次の歌詞が始まります。出るかどうかは間奏ごとの抽選で、確率は「控えめ」30%・「標準」50%・「エモい」65%・「超エモ」80%です（曲の冒頭は対象外）。
- **縁取り**の色は、明るい文字には黒、暗い文字には白が自動で選ばれます。
  - 黒背景の MP4 をスクリーン合成すると、黒い縁取りと影は消えます（黒は透明として扱われるため）。明るい MV に重ねるときは、「MV／曲と合成」か「PNG連番」を使ってください。
- **背景の色レイヤー**は、黒で暗くするだけでなく、紺やセピアなどで雰囲気を付けることもできます。「歌詞の表示中だけ」では、字幕が出る少し前に色がかかり、消えた少し後に戻ります（字幕の間が1秒未満なら、かかったままです）。
  - MP4 では使えません（黒はスクリーン合成で、グリーンはクロマキーで消えるため）。編集ソフト側で MV の明るさや色を調整してください。
  - PNG 連番では、歌詞の背面に半透明の色が入った画像になり、DaVinci Resolve で重ねると MV に色がかかります。
  - 色レイヤーと文字の明るさが近いと、文字が埋もれる旨の注意が表示されます。
- 背景を「黒」にしたときに暗い文字色を選ぶと、重ねたときにほとんど見えなくなるので、警告が表示されます。背景を「グリーン」にしたときの緑系の文字色も同様です。

## 書き出し形式の選び方

### どれを選べばいい？

| やりたいこと | 選ぶ出力形式 |
|---|---|
| **CapCut** などで MV に重ねたい | MP4（CapCut など）＋ 背景「黒」 |
| **DaVinci Resolve** などで MV に重ねたい | PNG連番・背景透過（DaVinci Resolve など） |
| 編集ソフトを使わず、**そのまま完成した動画**がほしい | MV／曲と合成（MP4・音声付き） |

### MP4（CapCut など）

- 歌詞だけが入った、背景が黒（またはグリーン）の動画です。
- CapCut での重ね方：
  - **背景が黒の場合（おすすめ）**：MV の上に「オーバーレイ」で追加し、「描画モード」を「**スクリーン**」にします。黒い部分が消えて、歌詞だけが残ります。
  - **背景がグリーンの場合**：MV の上に「オーバーレイ」で追加し、「**クロマキー**」で緑色を選んで消します。
- 縦型（9:16）で書き出した場合は、CapCut のプロジェクトの比率も 9:16 にしてください。

### PNG連番・背景透過（DaVinci Resolve など）

- 1コマずつの画像（PNG）が、連番のファイルとしてフォルダにまとめて保存されます。背景は透明です。
- 保存するときは、親フォルダを選びます。その中に新しいフォルダが作られ、画像が保存されます。
  - 同じ名前のフォルダがすでにあっても上書きしません（名前の末尾に `_2` などが付きます）。
- DaVinci Resolve での使い方：書き出したフォルダを「メディアプール」にドラッグします。連番の画像が1本の動画として読み込まれ、背景の透明もそのまま使えます。
- ファイル数と容量が大きくなります。1分あたり約1,800枚・約0.3〜0.6GB が目安です。保存先の空き容量を確認してください。

### MV／曲と合成（MP4・音声付き）

- 読み込んだ MV の上に歌詞を重ねた、**音声付きの完成した動画**を書き出します。
- 曲（音声だけのファイル）を読み込んだ場合は、黒い背景に歌詞が流れる動画になります。
- この形式を選ぶには、先に「1. 字幕・音源」の「MV / 音声を読み込む（任意・確認用）」で MV か曲を読み込んでおく必要があります。
- MV の縦横比と画面比率が違う場合は、画面いっぱいになるように拡大し、はみ出した部分は切り取ります。
- 1秒あたりのコマ数（fps）は、MV に合わせます（最大 60）。
- 音声は、できるだけ元のまま（音質が変わらない形）で入れます。

## 困ったとき

### 字幕ファイルが読み込めない

- 拡張子が `.srt` か `.sbv` か確認してください。
- 時間の書き方（`00:00:12,500 --> 00:00:15,000` など）が崩れていないか確認してください。
- 字幕ファイルは 1MB まで、字幕は 3,000 件までです。

### 保存先を選ぶ画面が出ない／出力形式が選べない

- Chrome または Edge の最新版を使ってください。PNG連番と合成は、この2つのブラウザでしか使えません。
- 「MV／曲と合成」は、MV か曲を読み込むまで選べません。

### MV が読み込めない・合成でエラーになる

- MV の形式によっては、ブラウザで読み込めないことがあります（特に HEVC／H.265 形式）。
- HandBrake などの変換ソフトで「H.264 の MP4」に変換してから、もう一度読み込んでください。

### 書き出しに時間がかかる

- パソコンの性能によって大きく変わります。書き出し中は残り時間の目安が表示されます。
- 書き出し中にページを閉じたり、再読み込みしたりしないでください。
- 演出レベルが高いほど、モーションブラーの計算で時間がかかります（「超エモ」は「演出なし」の数倍）。急ぐときは演出レベルを下げてください。

### 気に入った演出をもう一度作りたい

- 「演出を再生成」を押しすぎたときは、「1つ前に戻す」で前のパターンに戻れます。
- 後日同じパターンで作り直したい場合は、「パターン番号」を控えておいてください。同じ字幕・同じ設定（フォント・スタイル・字幕のタイミング）で番号を入力すると、同じ演出になります。
  - 演出レベルが「標準」以上で MV／曲を読み込んでいるときは、同じ MV／曲を読み込んだ場合だけ同じ演出になります。MV／曲を読み込まない場合は、字幕だけから作る演出になります。
- パターン番号や設定は、ブラウザには保存されません（ページを閉じると消えます）。

### 途中でキャンセルしたら「削除しますか？」と出た

- 途中まで書き出したファイル（またはフォルダ）が残っています。
- 不要なら「ファイルを削除する」（または「フォルダを削除する」）を、残したいなら「残す」を押してください。

---

## 制限

- 字幕ファイル：**1MB まで**、字幕は **3,000 件まで**
- 書き出しの長さ：**15 分まで**
  - 10 分を超えると（PNG 連番は 5 分を超えると）、時間と容量が大きくなる旨の注意が出ます。
- 時刻の打ち間違いの確認：次の場合に注意を表示します。
  - 前の字幕から 10 分以上離れている字幕がある。
  - 1つの字幕が 60 秒以上表示される。
- MV：ファイルの大きさの制限はありません。ただし 15 分を超える MV は、合成には使えません。

## プライバシー

- 字幕・MV・曲は、**あなたのブラウザの中だけで処理**され、インターネット上のどこにも送信されません。
- ブラウザにデータを保存することもありません。ページを閉じる、または「**データを破棄**」ボタンを押すと、アプリ内のデータは消えます。
- 書き出したファイルは、あなたが選んだ場所に保存されます。ブラウザのダウンロード履歴も含め、アプリから消すことはできないので、必要に応じてご自身で管理してください。

### 技術メモ

- 描画は Canvas 2D。書き出しは Worker 内で WebCodecs（H.264）と [Mediabunny](https://mediabunny.dev/) を使い、MP4 の生成と MV の読み込みを行う。
- PNG 連番と合成は File System Access API で保存先へ直接書き込む（メモリに溜めないので長尺でも容量の問題が起きない）。
- MP4（歌詞のみ）は全体をメモリ上に作ってから保存するため、10 分超で警告を出す。
- 本番ビルドは CSP（`index.html` の meta タグ）で外部接続を禁止している。localStorage / IndexedDB / Cookie / Service Worker は使わない。
- 曲のリズム解析（[src/audio/](src/audio/)）は、MV／曲を Worker で mediabunny によりデコードしながら、自前の FFT で STFT をとって行う（新しい依存は無い）。
  - 立ち上がりの強さ（対数のスペクトルフラックス）の自己相関とテンポの事前分布でテンポを推定し、裏拍・1拍おきの強さで倍・半分の取り違えを直す。拍は Ellis (2007) の動的計画法で追跡する。
  - 小節の頭は4拍子を仮定して低音の立ち上がりから、曲の区切りは拍ごとの音色の似ている度合い（Foote のノベルティ）から推定する。どれも推定であり、実曲では外れることがある。
  - 確からしさ（`confidence`）は立ち上がりの周期性から決め、ノイズや持続音だけの音では拍を返さない。
  - 演出を拍に合わせる計算は [src/director/beatSync.ts](src/director/beatSync.ts) にあり、結果（`TimelineItem.sync`・`Timeline.rhythm`）を Timeline に焼き込む。拍に合わせるのは演出レベルの「標準」以上（`Theme.syncToBeat`）で、サビの行だけ。曲を渡さない・確からしさが 0.3 未満・`beatSync` が無効・「演出なし」「控えめ」のときは、これらのキーを付けず、従来と完全に同じ Timeline になる（Timeline・描画命令のゴールデンで確かめている）。
  - 解析結果を耳で確かめるには、URL に `?beats=1` を付けて開く。プレビューの下に拍の確認が出て、拍で丸が点滅し、選べば拍ごとにクリック音が鳴る（書き出しには含まれない）。
- 制限値は [src/limits.ts](src/limits.ts) の `LIMITS` にまとめている。
- モーションブラーは、歌詞の層だけを複数の時刻で描いて平均する（背景と色レイヤーはブレさせない）。プレビューの再生中は描き重ねる数を減らしている。
- 画面の文言は [src/i18n/messages/](src/i18n/messages/) の辞書にある。英語（`en.ts`）が基準で、他の言語は型チェックでキーの抜けを検出する。ロジック側（検証・書き出しのエラー）は文言を持たず、キーと値を返して画面側で翻訳する。

### エフェクトの有効・無効（effects.config.json）

演出がうるさく感じる場合に、個別のエフェクトを後から外せます。画面には出さず、開発側だけが設定します。

- リポジトリ直下の [effects.config.json](effects.config.json) で、外したいキーを `false` にします。
- ビルド時に組み込まれるので、`main` に push すると Actions で自動的に公開版へ反映されます。
- キーを書き忘れた場合は有効（`true`）として扱います。
- 知らないキーや `true` / `false` 以外の値があると、テスト（`npm test`）が失敗してデプロイが止まります。その場合、公開版は前のまま残ります。

| キー | 無効にすると |
|---|---|
| `motionBlur` | モーションブラーをかけない |
| `outline` | 文字の縁取りをしない（スタイル欄のチェックボックスも出さない） |
| `dropShadow` | 文字の影を付けない（スタイル欄のチェックボックスも出さない） |
| `cameraShake` | サビ頭・セクション頭のカメラシェイクをしない |
| `glitch` | グリッチ（色ずれ）の演出を選ばない |
| `shine` | シャイン（光のスイープ）を付けない |
| `particles` | 光の粒を出さない |
| `cameraWork` | 疑似3Dのカメラワークを付けない |
| `diagonalLines` | サビの斜めラインを出さない |
| `sectionRing` | セクション頭の波紋を出さない |
| `echo` | 残響（残像）の演出を選ばない |
| `verticalText` | 縦書き・縦横混在にしない（スタイル欄の「縦書き」も出さない） |
| `interludeProgress` | 間奏の進み具合を表示しない |
| `bandWipe` | 帯ワイプの演出を選ばない |
| `slot` | スロットの演出を選ばない |
| `split` | スプリットの演出を選ばない |
| `outlineEcho` | アウトラインの反復の演出を選ばない |
| `underline` | 歌詞の線（横書きの下線・縦書きの右線）を引かない |
| `beatSync` | 演出を曲の拍に合わせない（曲の解析と BPM の表示は行う） |
| `beatPulse` | 拍ごとにサビの歌詞を弾ませない |
| `interludeMeter` | 間奏の進み具合に、曲の音量の波形を出さない（「エモい」「超エモ」のみで出るもの） |

- 演出の選ばれ方（乱数の順番）は変えずに、そのエフェクトだけを外します。そのため、同じシードでは、他の演出はそのまま残ります。
  - 例外として、`glitch`・`echo`・`bandWipe`・`slot`・`split`・`outlineEcho` は演出の候補から外すので、その行は別の演出に選び直されます。
